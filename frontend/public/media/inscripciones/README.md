# Imágenes para inscripciones

Guardá los fondos de cada campeonato con esta estructura:

`media/inscripciones/<categoria>/temporada-<numero>/`

Los nombres de categoría se normalizan en minúsculas, sin tildes y con guiones. Por ejemplo:

`media/inscripciones/turismo-carretera/temporada-2/banner-01.webp`

Se admiten archivos AVIF, WEBP, JPG, JPEG y PNG. Si hay varias imágenes, el Inicio mezcla el orden y las muestra como un carrusel automático.

La sección Formularios del panel administrativo crea estas carpetas y permite subir, revisar y eliminar las imágenes sin usar el administrador de archivos del servidor.
